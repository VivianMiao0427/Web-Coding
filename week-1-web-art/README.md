# A Quiet Tab Left Open

A one-page interactive web artwork for Week 1 of HTML and Hypertext Narratives.

## How to open it in VS Code

1. Open the `week-1-web-art` folder in Visual Studio Code.
2. Open `index.html`.
3. If you have the **Live Server** extension, click **Go Live** in the bottom-right corner.
4. Or double-click `index.html` in Finder to open it directly in a browser.

## What each file does

- `index.html` holds the artwork's content and structure.
- `style.css` creates the room, colors, layout, and animation.
- `script.js` reveals each object's memory and controls the lamp.
- `assets/memory.svg` is the small image inside the paper photograph.

## Artist statement

**A Quiet Tab Left Open** is a digital still life about how ordinary objects hold traces of our online lives. The laptop, mug, photograph, phone, and lamp each reveal a fragment when clicked. Moving between day and night makes the browser feel less like a tool and more like another object in the room—one that keeps waiting after we leave.

The piece uses one HTML page, CSS-drawn objects, a local image, hyperlinks, text, buttons, and a small amount of JavaScript.
